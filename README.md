# Bogdan Iachimciuc

I’m the founder of Smart Digital Administration and an engineering team lead. I build software for real operating workflows, from ordering and reservations for hospitality businesses to tools that connect Wear OS watches with scripts and AI assistants.

I’ve worked in software since September 2018. I started in telecom, provisioning applications on SIM cards, then moved into robotic process automation and helped prototype a browser that observed user workflows and suggested ways to automate them. I went on to test the performance of systems for a US client and later worked in software quality consulting and technical support, helping product teams and clients diagnose issues.

## Open-source projects

- [WearOS Index](https://github.com/iachimciucprojects-netizen/WearOS-Index) · A community-maintained catalog of Wear OS apps, development resources, and compatibility findings.
